# Assets de marca

Suba aqui os 18 PNGs de lockup e o manual de marca.

Sugestão de organização, para o design system da Fase 2 conseguir referenciar sem ambiguidade:

```
public/brand/
  lockup/empilhado-claro.png
  lockup/empilhado-escuro.png
  lockup/horizontal-claro.png
  lockup/horizontal-escuro.png
  lockup/selo-claro.png
  lockup/selo-escuro.png
  manual/manual-de-marca.pdf
```

Os nomes exatos não importam desde que fique claro, pelo nome, qual versão é para fundo claro e qual é para fundo escuro.

O monograma é S + S + B. Nunca "SB".
